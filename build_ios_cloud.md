# Облачная сборка iOS приложения

## Варианты автоматической сборки без Mac:

### 1. Codemagic (рекомендуется)
- Бесплатный план: 500 минут сборки/месяц
- Автоматическая сборка iOS
- Требуется GitHub/GitLab репозиторий

### 2. GitHub Actions
- Требуется Mac runner (платно)
- Или используйте бесплатные публичные runners (ограничено)

### 3. AppCircle
- Бесплатный план доступен
- Автоматическая сборка iOS

### 4. Bitrise
- Есть бесплатный план
- Поддержка Flutter iOS
