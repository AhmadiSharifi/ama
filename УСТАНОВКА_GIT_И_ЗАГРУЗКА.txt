  УСТАНОВКА GIT И ЗАГРУЗКА НА GITHUB
═══════════════════════════════════════════════════════════════

Git не установлен. Сначала установите его:

═══════════════════════════════════════════════════════════════
ШАГ 1: УСТАНОВИТЕ GIT
═══════════════════════════════════════════════════════════════

1. Скачайте Git для Windows:
   https://git-scm.com/download/win

2. Установите (все настройки по умолчанию - OK)

3. Перезапустите терминал

═══════════════════════════════════════════════════════════════
ШАГ 2: СОЗДАЙТЕ РЕПОЗИТОРИЙ НА GITHUB
═══════════════════════════════════════════════════════════════

1. Зайдите на https://github.com
2. Войдите или зарегистрируйтесь
3. Нажмите "+" → "New repository"
4. Название: amadeus-app
5. Выберите Private или Public
6. НЕ ставьте галочки (README, .gitignore)
7. Нажмите "Create repository"

═══════════════════════════════════════════════════════════════
ШАГ 3: ЗАГРУЗИТЕ ПРОЕКТ
═══════════════════════════════════════════════════════════════

После установки Git запустите: загрузить_на_github.bat

Или выполните вручную в терминале:

cd C:\Users\Admin\Desktop\AMADEUS
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_ЛОГИН/amadeus-app.git
git branch -M main
git push -u origin main

═══════════════════════════════════════════════════════════════
ШАГ 4: ПОДКЛЮЧИТЕ К CODEMAGIC
═══════════════════════════════════════════════════════════════

1. https://codemagic.io
2. Sign up (через GitHub)
3. Add application
4. Выберите репозиторий amadeus-app
5. Start build
6. Готово!
