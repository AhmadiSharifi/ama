СПОСОБ 1: ЧЕРЕЗ TOKEN (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════

1. Создайте Personal Access Token:
   - Зайдите на https://github.com/settings/tokens
   - Generate new token (classic)
   - Выберите срок действия (например, 90 дней)
   - Отметьте галочку "repo" (полный доступ к репозиториям)
   - Нажмите "Generate token"
   - СКОПИРУЙТЕ ТОКЕН (он показывается только один раз!)

2. Выполните команду:
   git push https://ВАШ_ТОКЕН@github.com/AhmadiSharifi/ama.git main

   Или используйте скрипт: загрузить_через_token.bat

═══════════════════════════════════════════════════════════════
СПОСОБ 2: ЧЕРЕЗ GITHUB DESKTOP (САМЫЙ ПРОСТОЙ)
═══════════════════════════════════════════════════════════════

1. Скачайте GitHub Desktop:
   https://desktop.github.com

2. Установите и войдите в GitHub

3. File → Add Local Repository
   Выберите папку: C:\Users\Admin\Desktop\AMADEUS

4. Нажмите "Publish repository"
   Готово!
