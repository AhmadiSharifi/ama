═══════════════════════════════════════════════════════════════

1. СОЗДАЙТЕ РЕПОЗИТОРИЙ НА GITHUB:
   - Зайдите на https://github.com
   - Войдите или зарегистрируйтесь
   - Нажмите "+" → "New repository"
   - Название: amadeus-app
   - Выберите Private или Public
   - НЕ ставьте галочки (README, .gitignore, license)
   - Нажмите "Create repository"
   - Скопируйте URL (например: https://github.com/username/amadeus-app.git)

2. ЗАПУСТИТЕ СКРИПТ:
   Дважды кликните: загрузить_на_github.bat
   
   Вставьте URL репозитория когда попросит
   Проект загрузится автоматически!

3. ПОДКЛЮЧИТЕ К CODEMAGIC ДЛЯ iOS:
   - Зайдите на https://codemagic.io
   - Sign up (можно через GitHub - 1 клик)
   - Нажмите "Add application"
   - Выберите ваш репозиторий amadeus-app
   - Codemagic автоматически найдет codemagic.yaml
   - Нажмите "Start new build"
   - Подождите 10-15 минут
   - Скачайте готовый .ipa файл для iOS!
