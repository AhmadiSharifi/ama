# Финальные инструкции - Как получить APK и AAB файлы

## ⚠️ Важно

Для сборки APK и AAB файлов **необходимо установить Flutter**. Это единственное требование.

## Быстрый способ (Windows)

1. **Установите Flutter:**
   - Скачайте: https://docs.flutter.dev/get-started/install/windows
   - Распакуйте в `C:\flutter` (или другую папку)
   - Добавьте `C:\flutter\bin` в PATH (переменные среды)

2. **Откройте терминал в папке проекта** и выполните:
   ```bash
   build.bat
   ```

   Или вручную:
   ```bash
   flutter pub get
   flutter build apk --release
   flutter build appbundle --release
   ```

3. **Готовые файлы будут в:**
   - APK: `build\app\outputs\flutter-apk\app-release.apk`
   - AAB: `build\app\outputs\bundle\release\app-release.aab`

## Альтернативный способ (если Flutter не установлен)

### Вариант 1: Использовать онлайн сервисы
- Некоторые онлайн сервисы могут собрать Flutter приложение (но это платно и не рекомендуется)

### Вариант 2: Попросить кого-то собрать
- Отправьте папку проекта тому, у кого установлен Flutter
- Он выполнит команды сборки

### Вариант 3: Установить Flutter (рекомендуется)
- Это займет 10-15 минут
- После установки вы сможете собирать приложения самостоятельно
- Flutter бесплатный и открытый

## Для публикации в магазинах

### Google Play:
- Загрузите AAB файл
- Заполните информацию о приложении
- Создайте Privacy Policy страницу
- Укажите URL политики в консоли

### App Store:
- Соберите iOS версию: `flutter build ios --release`
- Откройте в Xcode и заархивируйте
- Загрузите через App Store Connect

## Вопросы?

Если возникли проблемы:
1. Проверьте, что Flutter установлен: `flutter doctor`
2. Убедитесь, что зависимости установлены: `flutter pub get`
3. Проверьте интернет-соединение (нужен для первой сборки)
