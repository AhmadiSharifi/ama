  БЫСТРАЯ ИНСТРУКЦИЯ - ЗАГРУЗКА НА GITHUB
═══════════════════════════════════════════════════════════════

1. УСТАНОВИТЕ GIT (если еще не установлен):
   https://git-scm.com/download/win
   (Установите, перезапустите терминал)

2. СОЗДАЙТЕ РЕПОЗИТОРИЙ НА GITHUB:
   - Зайдите на https://github.com
   - Создайте новый репозиторий (без README)
   - Скопируйте URL

3. ЗАПУСТИТЕ СКРИПТ:
   загрузить_на_github.bat
   
   Вставьте URL репозитория когда попросит

4. ПОДКЛЮЧИТЕ К CODEMAGIC:
   - https://codemagic.io
   - Sign up через GitHub
   - Add application → выберите репозиторий
   - Start build
   - Готово!
