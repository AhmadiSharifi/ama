  ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ НА GITHUB
═══════════════════════════════════════════════════════════════

Git репозиторий инициализирован! Теперь загрузите на GitHub:

═══════════════════════════════════════════════════════════════
ШАГ 1: СОЗДАЙТЕ РЕПОЗИТОРИЙ НА GITHUB
═══════════════════════════════════════════════════════════════

1. Зайдите на https://github.com
2. Нажмите "+" в правом верхнем углу → "New repository"
3. Название: amadeus-app (или любое другое)
4. Выберите "Private" или "Public"
5. НЕ ставьте галочки (README, .gitignore, license)
6. Нажмите "Create repository"

═══════════════════════════════════════════════════════════════
ШАГ 2: ЗАГРУЗИТЕ КОД
═══════════════════════════════════════════════════════════════

GitHub покажет инструкции. Выполните в терминале:

git remote add origin https://github.com/ВАШ_ЛОГИН/amadeus-app.git
git branch -M main
git push -u origin main

Или используйте скрипт: загрузить_на_github.bat

═══════════════════════════════════════════════════════════════
ШАГ 3: ПОДКЛЮЧИТЕ К CODEMAGIC
═══════════════════════════════════════════════════════════════

1. Зайдите на https://codemagic.io
2. Sign up (можно через GitHub)
3. Add application
4. Выберите ваш репозиторий amadeus-app
5. Codemagic найдет codemagic.yaml автоматически
6. Start new build
7. Готово!
