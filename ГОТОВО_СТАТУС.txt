═══════════════════════════════════════════════════════════════

Для сборки APK и AAB файлов нужен Android SDK.

═══════════════════════════════════════════════════════════════
ВАРИАНТ 1: Установить Android Studio (рекомендуется)
═══════════════════════════════════════════════════════════════

1. Скачайте Android Studio:
   https://developer.android.com/studio

2. Установите Android Studio
   - При установке выберите "Android SDK"
   - SDK будет установлен автоматически

3. После установки запустите:
   .\flutter\bin\flutter.bat build apk --release
   .\flutter\bin\flutter.bat build appbundle --release

═══════════════════════════════════════════════════════════════
ВАРИАНТ 2: Установить только Android SDK Command Line Tools
═══════════════════════════════════════════════════════════════

1. Скачайте Command Line Tools:
   https://developer.android.com/studio#command-tools

2. Распакуйте в папку (например, C:\Android\sdk)

3. Установите необходимые компоненты через sdkmanager:
   sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

4. Установите переменную окружения:
   ANDROID_SDK_ROOT = C:\Android\sdk

5. Запустите сборку

═══════════════════════════════════════════════════════════════
